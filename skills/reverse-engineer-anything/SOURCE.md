# Source

Vendored unchanged from [morluto/rea](https://github.com/morluto/rea) at tag
`rea-agents-6.4.0` (`.agents/skills/reverse-engineer-anything/`), MIT licensed
(see `LICENSE`). It is the skill `npx rea-agents setup` would install, kept here
so every machine gets it from `ai-refresh` alongside the `rea` MCP server in
`claude/mcp-servers.json`.

To upgrade, bump the version pinned there and re-copy this directory from the
matching tag, so the instructions describe the tools the server actually has.
